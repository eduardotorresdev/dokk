How it works

One binary. The whole server.

Dokku is a great mini-Heroku, but setting it up means a bootstrap script, a few plugins, and a terminal for everything after. dokk collapses that into a single download and a browser tab.

01

Install dokk

Run the one-liner as root on a fresh Ubuntu or Debian box. It picks your arch, verifies the checksum and starts a systemd service.

$ curl -fsSL …/install.sh | sudo sh
✓ dokk v0.1.0 (linux/arm64)
✓ sha256 ok
✓ systemd: dokk.service active
→ http://127.0.0.1:7070
02

Open the panel

Create your superuser. The onboarding checks the server and, if Dokku is missing, installs it with the official bootstrap.sh, live, from the browser.

Features

Everything you'd otherwise do over SSH.

dokk doesn't replace Dokku. It drives it, with the same commands you'd type, and shows you what's happening.

Guided onboarding

Detects an existing Dokku or installs it. Sets the global domain (or sslip.io with zero DNS), Let's Encrypt email, and takes you to the first deploy.

Live dashboard

Every app with its status, processes and share of the machine, pushed over SSE. Host CPU, memory and disk at a glance. Filter, sort, group.

App detail

Streaming logs, build log per deploy, deploy history, ports, linked services. Start, stop, restart, rename, or remove with progress.

Deploy from any registry

Docker Hub, GHCR, GitLab or your own. Log in once with registry:login, then install any published tag straight from the Versions tab.

Env vars editor

Add, edit, reveal and copy variables. Paste a whole .env into any field and it splits into rows. Restart on save, or not.

Domains & HTTPS

Per-app domain and Let's Encrypt certificate from the wizard. See expiry on each card, renew in one click, keep auto-renewal on.

Superuser login

First run asks you to create the admin account, or set DOKK_USER / DOKK_PASSWORD. Sessions in a cookie, data in /var/lib/dokk.

Three languages

English, Español and Português (BR), switchable from the panel.

More deploy methods soon

Git push, Dockerfile and buildpacks are on the roadmap. Today dokk deploys prebuilt Docker images.

Requirements

A Linux box with root. That's the list.

dokk runs anywhere Dokku already runs. For a brand-new server where dokk installs Dokku itself, you need a distro Dokku's official installer supports.

FAQ

Questions people ask first.

Is dokk a replacement for Dokku?

No. dokk is a panel on top of Dokku. Every action in the UI is a real Dokku command run on the server, so you can keep using the dokku CLI, plugins, and git push alongside it. Remove dokk and your apps keep running.

I already have Dokku. Can I use dokk?

Yes. The onboarding detects the existing install and its version, skips the installer, and lists your current apps. Nothing is changed unless you ask.

Is it safe to expose port 7070?

By default dokk listens on 127.0.0.1:7070, so it isn't reachable from outside. The simplest secure access is an SSH tunnel: ssh -L 7070:127.0.0.1:7070 root@SERVER, then open http://localhost:7070.

If you want it on the network, put it behind a reverse proxy with TLS (nginx, Caddy, Dokku itself), or set DOKK_ADDR=0.0.0.0:7070 at install time and restrict with a firewall. dokk has a superuser login, but it runs as root, so treat it like SSH access.

What can I deploy today?

Prebuilt Docker images from any registry: public ones directly, private ones after a registry login. Git push, Dockerfile and buildpack deploys through the panel are coming; they work via the Dokku CLI meanwhile.

How do I upgrade or uninstall?

Upgrade: run the install one-liner again. It downloads the latest release and restarts the service. Pin a version with DOKK_VERSION=v0.1.0.

Uninstall: systemctl disable --now dokk && rm /usr/local/bin/dokk /etc/systemd/system/dokk.service. Data lives in /var/lib/dokk. Dokku and your apps are untouched.

What does the installer actually do?

Detects your architecture, downloads the latest release from GitHub, verifies the sha256 from checksums.txt, installs to /usr/local/bin/dokk, and creates and starts a dokk systemd unit. Set DOKK_NO_SERVICE=1 to skip the service. You can also grab dokk_linux_amd64.tar.gz or dokk_linux_arm64.tar.gz from the releases page and do it by hand.
